# Wisconsin-Breast-Cancer-veri-seti-uzerinde-ikili-siniflandirma-pipeline-
Wisconsin Breast Cancer veri seti üzerinde uçtan uca ikili sınıflandırma pipeline'ı (Logistic Regression, scikit-learn) geliştirdim; EDA, özellik seçimi ve StandardScaler tabanlı ön işleme adımlarını içeren pipeline
**Kullanılan Teknolojiler**
* Python (Pandas, NumPy)
* Scikit-Learn
* Matplotlib, Seaborn

**Kurulum ve Kullanım**
Gerekli bağımlılıkları kurmak için:
`pip install pandas numpy matplotlib seaborn scikit-learn`

İş akışını başlatmak için:
`python project.py`

**Otomatik Üretilen Çıktılar**
Script çalıştırıldığında proje dizinine otomatik olarak kaydedilen dosyalar:
* `1_correlation_heatmap.png`
* `2_confusion_matrix.png`
* `results_report.txt`
